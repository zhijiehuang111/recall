# 評 Grade

`recall` 與 `create-topic` 共用。使用者作答完成後才評。

## 四級

依作答過程評，取第一個符合的：

| Grade | 條件 |
|---|---|
| `again` | 放棄、進入 Teaching，或被指出錯誤後仍補不起來 |
| `hard` | 用了 Hint 才答出、漏了 Rubric 要點，或說錯被指出後才改對 |
| `good` | 沒用 Hint，Rubric 要點都答到且沒有說錯 |
| `easy` | 符合 `good`，還有正確的延伸 |

答得不完整不給 `good`：講得含糊、只說出名詞沒講出要點，都算漏。

Build Card 連驗收條件一起對照：驗收沒過，或做法不符 Rubric，都算說錯。

## 怎麼說

1. 逐條對照 Rubric 要點：答到哪些、漏了哪些、哪裡說錯。只描述缺口與錯處，正確寫法留給使用者自己補。
2. 給出 Grade 與一句理由，指向上表的條件。
3. 問使用者是否接受。使用者要改 Grade 時：
   - 改得比你低：直接採用。
   - 改得比你高：進入過 Teaching 的維持 `again`。其他情況說一次你的依據（漏了哪個 Rubric 要點、用了幾次 Hint），並提醒評高會讓這張卡隔更久才再考。使用者聽完仍堅持，就用使用者的。

`--hints` 填這張卡作答過程中給出的 Hint 次數。
